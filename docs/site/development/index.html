Get started

This guide covers the current development tree after 0.0.4. It is a preview, not the documentation for the published 0.0.4 binary. Work through the programs in order: write a source file, check it, run it, then build a native executable. The later sections explain values, arrays, slices, vectors, generics, enums, control flow, structs, pointers, raw memory, results, imports, input, and networking. Links at the end give full API contracts.

On Apple Silicon macOS, install Xcode Command Line Tools, CMake 3.28+, Ninja, OpenSSL 3, and LLVM/MLIR 21.1.6. From a source checkout:

brew install cmake ninja openssl@3
bash scripts/install-llvm.sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DLLVM_DIR=/opt/homebrew/opt/llvm/lib/cmake/llvm \
  -DMLIR_DIR=/opt/homebrew/opt/llvm/lib/cmake/mlir
cmake --build build -j 2

On Ubuntu 24.04 ARM64 or x86_64, install CMake 3.28+, Ninja, a C++23 compiler, OpenSSL 3, and the shared LLVM/MLIR 21.1.8 packages:

sudo apt-get update
sudo apt-get install -y cmake ninja-build g++ openssl libssl-dev
bash scripts/install-llvm-linux.sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DLLVM_DIR=/usr/lib/llvm-21/lib/cmake/llvm \
  -DMLIR_DIR=/usr/lib/llvm-21/lib/cmake/mlir
cmake --build build -j 2

Install with cmake --install build --prefix "$HOME/.local" if you want a reusable compiler and standard modules. A packaged gloinc needs the matching platform toolchain to start: LLVM/MLIR 21.1.6 on macOS or 21.1.8 on Ubuntu. The archive does not bundle it. Run the matching install-llvm.sh or install-llvm-linux.sh under share/gloinc/scripts/ before invoking bin/gloinc. Executables produced by Gloin do not need LLVM at runtime.

./build/gloinc --jit hello.gloin
./build/gloinc hello.gloin
./a.out

Compiler and native output

Run the following commands from the directory containing your source file. By default, the compiler builds a standalone executable for the current supported host named a.out; use -o PATH to choose its name. --jit or its alias --run executes the source immediately. --check validates a file without running it.

gloinc [--jit | --run | --check | --emit-ir | --emit-llvm | --emit-object | --emit-exe] \
       [-O0 | -O2] [-o PATH] [--stdlib-dir DIR] [--] FILE [-- ARG...]
gloinc --help
gloinc --version
ModeBehavior
default / --emit-exeLink a standalone host executable with the static Gloin runtime. Output is a.out unless -o PATH is supplied. Pass arguments directly to the executable.
--jit / --runJIT runs main() -> i32. Its low eight bits become the compiler process exit status. A program returning 42 exits with status 42; that alone does not print 42. Use FILE -- ARG... for program arguments.
--checkParse, type check, and verify without running. Main is optional.
--emit-ir, --emit-llvmPrint verified high level or LLVM dialect MLIR for inspection.
--emit-object -o PATHWrite a native object with a process entry point. Link it with libgloin_runtime.a using the pinned clang++.
--emit-exeExplicit spelling for the default executable mode.

Native object and executable output default to -O0. Add -O2 to run LLVM's O2 IR pipeline before native code generation, for example gloinc -O2 -o hello hello.gloin. Optimization flags apply only to native output, not JIT or inspection modes. They do not change the language's checked arithmetic and pointer rules. Source, output, and link errors go to stderr and exit 1. Usage errors exit 2. Successful checks and emission exit 0. Runtime arithmetic traps terminate the program. Quote paths with spaces. --stdlib-dir DIR selects a directory of @ modules. The compiler reports source locations for rejected code.

Source and declarations

Source is UTF-8; identifiers use ASCII letters, digits, and underscores. Comments start with //. Bindings, assignments, call statements, returns, imports, and defer statements end in ;. Function and control flow bodies use braces with no trailing semicolon. Declarations start with def; pub or priv follows def, with private as the default across modules.

def const LIMIT: i32 = 42;
def pub calculate(x: i32) -> i32 { return x + LIMIT; }
// Inside a function:
def count: i32 = 0;      // Binding cannot be reassigned.
def mut total: i32 = 0;  // Binding can be reassigned.
total = total + count;

All bindings, parameters, fields, and return types need explicit types. A local may be declared without an initializer, then assigned before use. def const defines a compile time value; its expression cannot call a runtime function. Names in an inner block can shadow outer names. Assignments are statements, not expressions. There are no implicit numeric conversions or overloads.

Integer literals accept decimal, 0x hexadecimal, and 0b binary spelling. Floating literals use decimal spelling and a type context. The context of a binding, parameter, field, or return can select a literal's type. Gloin does not implicitly convert one typed numeric value to another.

Expressions have unary - and !; arithmetic + - * / % (remainder is integer only); comparisons == != < <= > >=; and boolean && ||. Parentheses control grouping. Arithmetic binds before comparisons, and comparisons before boolean operators. && and || short circuit; other operands and call arguments evaluate left to right. Integer overflow, division by zero, and non-finite floating results trap at runtime; invalid constant expressions fail during checking.

Fixed arrays

A fixed array has an element type and a length known when you compile. Write its type as [T; N] and initialize it with exactly N values in braces. Indexes start at zero. This complete program prints sum = 42:

import "@std";

def sum(values: [i32; 4]) -> i32 {
    def mut total: i32 = 0;
    for def mut i: usize = 0; i < 4; i = i + 1 {
        total = total + values[i];
    }
    return total;
}

def main() -> i32 {
    def mut values: [i32; 4] = {8, 13, 7, 10};
    values[3] = 14;
    if sum(values) != 42 { return 1; }
    std.println("sum = 42");
    return 0;
}

An array is a value: assigning it, passing it to a function, or returning it copies its elements. [i32; 2] and [i32; 3] are different types. An array literal needs a type context from a binding, parameter, field, or return; [1, 2] is not an array literal. Nested arrays use nested braces, such as def grid: [[i32; 2]; 2] = {{1, 2}, {3, 4}};. Empty arrays use [i32; 0] = {}.

Every indexed read or write checks 0 <= index < N and traps on failure, including any access to a zero-length array. Writing an element requires writable storage. &values[0] borrows a live element; it does not extend that element's lifetime. A pointer to an array points to the whole array, not its first element. Fixed arrays support checked slice ranges such as values[1..3]. A nullable pointer to an element can use signed element offsets; pointer offsets do not carry the array's bounds check. A declared array may use zeroed when its element type has a zero value: integer 0, float 0.0, false, null nullable pointer, empty string, or recursively zeroed nested array. It still allocates its full storage. {value; N} evaluates one value and copies it into all N elements. Arrays of non-null references, structs, and enums cannot use zeroed. See the detailed guide and the packaged fixed_arrays.gloin example.

Borrowed slices and vectors

A [T] slice is a pointer and length view of existing contiguous storage. It does not own or copy elements. A writable array can produce values[..], values[1..], or values[1..3]; the end is exclusive. The same ranges work on slices. The compiler checks range and index bounds. .len is a read-only u64. A [const T] slice permits reads only. Keep the underlying array or arena alive while using a slice.

def main() -> i32 {
    def mut values: [i32; 4] = {1, 2, 3, 4};
    def middle: [i32] = values[1..3];
    middle[0] = 20;
    return values[1] + middle[1]; // 23
}

Import @vector to use one of two vector types. vector.Vector<T; N> stores N initialized slots inline and a logical length. It has no arena allocation; push returns false when full. vector.Vector<T> stores elements in a caller-owned GeneralArena and grows its capacity when pushed. Use Vector<T>.empty(&memory, capacity) to reserve uninitialized spare slots, including for struct or enum elements with no zero value. The older create(&memory, capacity, fill) remains available; it evaluates but no longer stores the fill value in spare slots. Both forms provide len(), cap(), push(value), get(index), get_mut(index), and clear(). Get methods return nullable pointers; check for null before dereferencing.

import "@vector";

def main() -> i32 {
    def mut values: vector.Vector<i32; 2> = vector.Vector<i32; 2>.create(0);
    if !values.push(20) || !values.push(22) { return 1; }
    if values.push(99) { return 2; }
    def first: *const i32 = values.get(0);
    if first == null { return 3; }
    return *first + 22;
}

For a growable vector, create an arena and call vector.Vector<i32>.empty(&memory, 2). Growth allocates a new buffer in that arena. Both vector forms now support as_slice() and as_const_slice() over live elements, plus append_from, insert, remove, truncate, and pop. The growable form also supports reserve. A view captures the current length; it never exposes spare capacity. Treat pointers and views as invalid after growth or a moving reserve; arena reset/free invalidates all arena vector storage. Copying a growable vector copies its descriptor, so copies can disagree about length and capacity. Copying a fixed vector copies its entire inline buffer. @slices adds generic fill, reverse, and nonoverlapping copy helpers. See the ownership and API guide and packaged examples.

Generics and enums

Generic structs, functions, and methods use explicit type arguments. A generic struct can also take a compile-time size parameter after a semicolon. The size becomes part of its type and layout; it may size a fixed array field. The compiler specializes checked bodies for concrete arguments. There is no inference for generic function or method calls.

def struct Box<T> {
    def pub value: T,
    def pub static create(value: T) -> Box<T> {
        return Box<T> { value: value };
    }
}

def identity<T>(value: T) -> T { return value; }

def main() -> i32 {
    def box: Box<i32> = Box<i32>.create(42);
    return identity<i32>(box.value);
}

A type such as Buffer<i32; 16> supplies one type and one compile-time capacity. A method may declare its own type parameters and is called with explicit arguments, for example pair.with_third<bool>(true). See the generic rules and limits.

Enums currently carry no payload. Declare def enum Direction { North, East, South, West }, construct Direction.North, and compare variants of the same enum with == or !=. Export with def pub enum across modules. There is no match expression, variant payload, integer conversion, or guaranteed foreign ABI. See the enum guide.

Functions and control flow

Functions declare the type of every parameter and an explicit return type. The root source file needs def main() -> i32 to run or emit native output. Other functions may return void. This program returns 42 as its exit status:

def add(a: i32, b: i32) -> i32 { return a + b; }
def main() -> i32 {
    def mut total: i32 = 0;
    for def mut i: i32 = 0; i < 3; i = i + 1 {
        if i == 1 { total = add(total, 20); }
        else { total = add(total, 11); }
    }
    return total;
}

Use if/else, unless (run a body when its condition is false), while, and C style for with braced bodies. break and continue are not part of this release. Functions may call later declarations and recurse. A non-void function must return a value on every reachable path. An early return exits the function.

defer call(...); schedules a function call for normal function exit. Its arguments are evaluated and captured when execution reaches the defer; deferred calls run in reverse registration order. A runtime trap does not run them. Use this for cleanup such as defer memory.free();.

Structs and methods

A struct groups named, typed fields. Struct values copy by value. Separate a struct's fields with commas and construct a value with every required field. A field can be reassigned only if its declaration uses def mut. Methods declare a typed self parameter; static methods have no self. This complete program also returns 42:

def struct Counter {
    def mut value: i32,
    def static make(value: i32) -> Counter {
        return Counter { value: value };
    }
    def add(self: &Counter, amount: i32) -> void {
        self.value = self.value + amount;
    }
    def read(self: &const Counter) -> i32 { return self.value; }
}

def main() -> i32 {
    def mut counter: Counter = Counter.make(40);
    counter.add(2);
    return counter.read();
}

Inside its declaring module, a method can read private fields. Other modules can use only pub members. A method receiver may be a struct value, reference, or pointer of the declared kind. The compiler checks whether writes through self are allowed. Recursive structures use pointer or reference fields; by-value recursive layout is rejected.

Pointers, references, and &*p

Gloin makes nullability visible in the type. *T is a pointer that may hold null. &T is a reference to an existing initialized T and cannot be null. Adding const after * or & makes the pointee read-only. Neither form allocates or owns memory.

SourceMeaning
def mut x: i32 = 41;
def r: &i32 = &x;		&x takes the address of an initialized, writable place. r cannot be rebound, but *r = 42; can change x.
def mut p: *i32 = r;A non-null reference can weaken to a nullable pointer. The reverse conversion is never implicit.
if p != null { add_one(&*p); }&*p is an expression: dereference p, check it for null, and create a non-null reference. If p is null, evaluation traps. The check does not prove the storage is still alive.
def slot: &*i32 = &p;&*i32 is a type: a non-null reference to a nullable *i32 variable. It is not a nullable reference. *slot = null; changes the pointer stored in p.

The same characters mean different things in a type and in an expression: &*i32 nests the reference and pointer types, while &*p takes a reference through the pointer value named p. There is no nullable reference type in the current language. Use *T for an optional address, and &*T when a function needs to rebind an existing optional pointer slot.

This complete program exercises both forms and returns 42. set_slot receives a non-null reference to the nullable pointer variable. add_one receives a non-null reference to the integer behind that pointer.

def add_one(value: &i32) -> void { *value = *value + 1; }
def set_slot(slot: &*i32, value: *i32) -> void { *slot = value; }

def main() -> i32 {
    def mut answer: i32 = 41;
    def reference: &i32 = &answer;
    def mut pointer: *i32 = null;
    set_slot(&pointer, reference);
    if pointer == null { return 1; }
    add_one(&*pointer);
    return answer;
}

Dereferencing a null pointer, using p.field when p is null, or evaluating &*p when p is null traps. null needs a pointer type from context; it cannot initialize &T. A pointer is not a boolean: compare it with null. Pointer comparisons compare addresses, not values. There is no arbitrary pointer cast.

A nullable data pointer *T can advance by a signed i64 number of elements: p + offset. This complete program returns 32:

def main() -> i32 {
    def mut values: [i32; 3] = {10, 20, 12};
    def first: *i32 = &values[0];
    def second: *i32 = first + 1;
    return *second + *(second + 1);
}

Run the packaged pointer_offsets.gloin with gloinc --jit, or build it with gloinc -O2 -o pointer-offsets pointer_offsets.gloin. Adding any offset to null traps, including zero. Pointer offsets do not check allocation bounds: keep both addresses within the same live allocation or one past its end, and never dereference one past. &T, void and function pointers cannot be offset; pointer subtraction, ordering, and indexing remain unsupported. Fixed-array indexing retains its runtime bounds check. See the full pointer-offset contract.

Only the outer pointer layer may weaken from writable to read-only or from reference to pointer. Binding mutability and pointee mutability differ: def p: &i32 cannot rebind p but can write *p; def mut p: *const i32 can rebind p but cannot write *p. You may take an address only of initialized, addressable storage, not a literal or temporary.

Memory management is manual. Gloin has no borrow checker or lifetime tracking. A reference must still point to live storage after a null check; copying or returning an address does not extend the value's life. @arena provides GeneralArena for initialized typed allocation. reset() invalidates all values in that arena while retaining blocks; free() releases them. See the arena guide for allocation and failure behavior.

Raw memory and custom arenas

Import @memory when a custom allocator needs an individual native block. memory.alloc(bytes, alignment) returns a nullable *u8 over uninitialized bytes; invalid sizes or alignment and allocation failure return null. memory.free(pointer) accepts null, or the original pointer returned by alloc exactly once. size_of<T>(), align_of<T>(), and padding<T>(pointer) expose target layout. place<T>(pointer, available, value) checks null, alignment, and the stated available byte count, then writes a copy of the value and returns *T; failure returns null without writing.

import "@memory";

def main() -> i32 {
    def block: *u8 = memory.alloc(64, 16);
    if block == null { return 1; }
    defer memory.free(block);
    def number: *i32 = memory.place<i32>(block, 64, 42);
    if number == null { return 2; }
    return *number;
}

The caller must provide the true remaining writable byte count, keep the block live, and never read uninitialized bytes. free does not destroy placed values; pointers into the block become invalid after free. Runtime traps do not run defers. See the raw memory contract and the packaged custom_arena.gloin example for a complete bump arena.

Results and errors

result<T> and error are built-in lowercase types and reserved words in this development compiler. Source that used either as an identifier in 0.0.4 must rename it. A result<T> holds exactly one success value or one error. result<void> allows a success without a value; result<error> is invalid. Returning a T or an error from a function declared result<T> wraps that branch automatically. An error is constructed from one string literal, for example error("invalid input"). Its read-only .message is a static Gloin string.

import "@std";

def increment(text: string) -> result<i32> {
    def number: result<i32> = std.parse_i32_checked(text);
    if number.erroneous { return number.error; }
    return number.value + 1;
}

def main() -> i32 {
    def answer: result<i32> = increment("41");
    if answer.erroneous {
        std.println(answer.error.message);
        return 1;
    }
    return answer.value;
}

Every result binding, including a parameter, must be checked with .erroneous on every path that leaves its scope. The compiler permits .value only on a proven success path and .error only on a proven failure path. Direct if r.erroneous, if !r.erroneous, and unless r.erroneous establish proofs; a branch that returns can establish the opposite proof afterward. Reassigning a mutable result requires a new check. A result call cannot be discarded. Propagation is explicit: return the checked .error; a whole result cannot be returned directly.

Errors currently contain a static message only. They have no source location, stack trace, or debug payload. Results cannot currently be stored as struct fields or behind pointers, arrays, or slices; access requires a named binding. A successful pointer or borrowed string payload keeps its ordinary lifetime rules. The complete result contract explains flow checks and GloinIR lowering. The packaged result_handling.gloin example demonstrates success and forwarding.

Modules

Put these two files in one directory. The imported file gives an ordinary function public visibility. The root file calls it through the module name:

guide_utils.gloin

def pub twice(x: i32) -> i32 { return x + x; }

main.gloin

import "./guide_utils";

def main() -> i32 { return guide_utils.twice(21); }

gloinc --jit main.gloin exits with status 42; gloinc main.gloin writes a.out. @name loads name.gloin from the standard library directory. Relative imports resolve from the importing source file. import "./foo"; loads foo.gloin when there is no foo/ directory; if the directory exists, it collects its immediate .gloin files into one foo namespace. Use ./foo.gloin to choose the file when both exist. import "#foo"; collects packages/foo/*.gloin beside the root source file. Directory imports need no entry file and do not download packages. A module exposes its pub declarations through its namespace. Only the root file supplies main; imports have no runtime initialization. Import cycles, missing files, duplicate declarations, and private access produce diagnostics. See the module guide and runnable example.

Input and standard library

Standard modules use the same import and namespace rules. Output is explicit: a return value sets the exit status but does not print. std.print writes bytes without a newline and std.println adds one. std.input returns a status-bearing struct because EOF is a normal outcome; checked parsing returns result<i32> for invalid text or overflow. This program reads a decimal integer, adds one, and prints it. Try printf '41\n' | gloinc --jit next.gloin.

import "@std";
import "@arena";

def main() -> i32 {
    def mut memory: arena.GeneralArena = arena.GeneralArena.create();
    defer memory.free();
    def line: std.InputResult = std.input(&memory, 64);
    if line.status != std.OK { return 1; }
    def parsed: result<i32> = std.parse_i32_checked(line.value);
    if parsed.erroneous {
        std.println(parsed.error.message);
        return 2;
    }
    std.println(std.to_string(&memory, parsed.value + 1));
    return 0;
}

line.value borrows bytes owned by memory. Use it before memory.reset() or memory.free(). The example treats every non-OK input status as exit 1; a larger program can distinguish std.END, std.NO_MEMORY, and other errors. std.to_int remains available with its status struct. The standard library guide lists the exact statuses and signatures.

Symbolic links

fs.symlink(target, link_path) -> result<void> creates a new link and never replaces an existing entry. It stores the target text verbatim; a relative target resolves from the link's containing directory when followed. The target may be absent or cyclic.

fs.read_link(&memory, path, max_bytes) -> result<string> reads the immediate link's stored text into caller-owned arena storage. Check .erroneous before using the value. An exact byte limit succeeds; longer text fails without truncation. It allocates max_bytes + 1 bytes, retained until arena reset/free even on a host error. Errors currently provide static messages, without errno.

fs.metadata reports the final link, and fs.remove_file removes it while leaving its target untouched. Directory components still follow ordinary host resolution rules; these operations do not confine paths. Read the complete contract and run the example:

./build/gloinc --jit examples/symlinks.gloin -- absent ./demo-link

This creates a new broken link, prints Stored target: absent, and removes the link. An existing ./demo-link is preserved and reported as an error.

Filesystem workspaces

@fs provides filesystem operations with built-in result<T> errors:

Canonical paths are snapshots and do not reserve filesystem objects or confine later operations.

./build/gloinc --jit examples/temporary_workspace.gloin -- ./build

The complete example writes a file in a unique directory and uses defer to clean up in reverse order. Read the full bounds, cost and ownership contract. The formatter test driver uses these APIs and process capture in Gloin; its private recursive cleanup assumes a stable owned fixture tree.

Checked file replacement

fs.replace_file(path, expected, replacement) -> result<void> checks an existing regular file against previously read bytes, stages new contents in an exclusive sibling file, preserves uid/gid and ordinary Unix permissions, and renames it over the source. Final symlinks, hard links, non-owner files and special mode bits are rejected. Errors before rename preserve the original.

The caller must have exclusive editing access: the last comparison and rename are separate calls. ACLs, extended attributes and timestamps are not copied, and crash durability is not promised. Read the full contract before using it. gloinfmt --write --git uses this API after checking token preservation and idempotence; see the formatter guide.

Child processes

@process launches an explicit executable with a slice of arguments and built-in result<T> errors. Arguments remain separate and literal. The child inherits standard streams, cwd and environment; other file descriptors are closed. There is no implicit shell or PATH lookup.

import "@arena";
import "@process";
import "@std";

def cleanup(child: &process.Child) -> void {
    def closed: result<void> = child.close();
    if closed.erroneous { std.println(closed.error.message); }
}

def main() -> i32 {
    def mut owner: arena.GeneralArena = arena.GeneralArena.create();
    defer owner.free();

    def arguments: [string; 2]         = {"Hello from Gloin", "$HOME stays literal"};
    def started: result<process.Child> = process.start(&owner, "/bin/echo", arguments[..]);

    if started.erroneous {
        std.println(started.error.message);
        return 1;
    }

    def mut child: process.Child = started.value;
    defer cleanup(&child);

    def finished: result<process.ExitStatus> = child.wait();
    if finished.erroneous {
        std.println(finished.error.message);
        return 2;
    }

    def closed: result<void> = child.close();
    if closed.erroneous {
        std.println(closed.error.message);
        return 3;
    }

    def exit_status: process.ExitStatus = finished.value;
    if !exit_status.success() { return 4; }

    std.println("Child exited successfully");

    return 0;
}

This prints Hello from Gloin $HOME stays literal, followed by Child exited successfully. Normal nonzero exits and signal termination are values in ExitStatus; launch and wait failures are errors. poll() observes without blocking, wait() reaps and caches status, and terminate()/kill() request termination. Copies share state. close() kills an unfinished child, waits, and invalidates all aliases; call it before resetting the owner arena.

Pipes and bounded capture

start_piped connects independent stdin, stdout and stderr pipes. communicate feeds input while draining both outputs into caller-owned buffers, closes stdin, and waits for EOF and child exit. All fallible calls use built-in result<T>.

// Binary stdin and bounded stdout/stderr capture with a five-second deadline.
import "@arena";
import "@process";
import "@std";
import "@strings";
import "@time";

def cleanup(child: &process.Child) -> void {
    def closed: result<void> = child.close();
    if closed.erroneous { std.println(closed.error.message); }
}

def main() -> i32 {
    def mut owner: arena.GeneralArena = arena.GeneralArena.create();
    defer owner.free();

    def arguments: [string; 0]         = {};
    def started: result<process.Child> = process.start_piped(&owner, "/bin/cat", arguments[..]);

    if started.erroneous { std.println(started.error.message); return 1; }

    def mut child: process.Child = started.value;
    defer cleanup(&child);

    // 72, 105, 10 are the counted bytes of "Hi\n". NUL bytes are supported too.
    def input: [u8; 3]         = {72, 105, 10};
    def mut output: [u8; 1024] = zeroed;
    def mut errors: [u8; 1024] = zeroed;
    def captured: result<process.Output> = child.communicate(input[..], output[..], errors[..],
        time.Duration { nanoseconds: 5000000000 });

    if captured.erroneous { std.println(captured.error.message); return 2; }

    // communicate closed the pipes, reaped the child and invalidated its aliases.
    // These views still borrow our buffers; they do not borrow the child handle.
    def outcome: process.Output = captured.value;

    std.print(strings.view_bytes(outcome.stdout));

    if !outcome.status.success() { return 3; }
    if outcome.stdin_written != input[..].len { return 4; }

    return 0;
}

This prints Hi. Input and output buffers must be separate and remain live; returned slices borrow the output buffers. Bytes including NUL are preserved. Each buffer is a strict limit: exact-length output succeeds, overflow is an error. A child may close stdin early; stdin_written records bytes accepted by the pipe, not proof they were read. Nonzero exits remain ordinary ExitStatus values.

The duration begins at communication entry. Expiration or failure closes pipes and kills/reaps the direct child; cleanup can outlast the deadline. Successful communication also closes the handle and its aliases. wait_timeout instead returns ready = false on expiration and leaves the child owned. For manual streaming use write_stdin, close_stdin, read_stdout, read_stderr and wait_io. Never wait indefinitely on a child whose output pipes you are not draining.

Child settings and group cleanup

Current policy: group cleanup is opt-in. start, start_piped and default Options manage only the direct child. Set new_process_group = true to give a tool and its ordinary workers a separate cleanup group. Set piped = true independently when capture is needed. Pipes and communication deadlines do not automatically enable group cleanup.

We chose process groups as a common macOS/Linux mechanism for foreground tools and test servers, using ordinary process permissions. Defaults preserve inherited-group behavior and cleanup never targets the parent's inherited group. Descendants may create another group/session and survive; scanning the process tree would still race with forks, exits and reparenting. Full containment would require separately implemented platform support. Read the setup sequence, behavior table, reasoning and future strict-mode policy.

start_with accepts process.Options.defaults(). Set cwd to change only the child directory; relative executables resolve there. With inherit_environment = false, environment supplies the complete environment as unique NAME=value strings. Empty values are valid; NUL bytes, missing names/separators and duplicates are rejected. Supplying entries while inheriting is also an error. The parent settings remain unchanged.

stack_limit_bytes defaults to zero (inherit). Set 2097152 for a 2 MiB child soft stack limit before execution. The hard limit and parent settings remain unchanged. Invalid or unsupported requests return a built-in error; they do not silently inherit instead.

// Child cwd, environment, pipes, process-group cleanup and a 2 MiB soft stack limit.
import "@arena";
import "@process";
import "@std";
import "@strings";
import "@time";

def cleanup(child: &process.Child) -> void {
    def closed: result<void> = child.close();
    if closed.erroneous { std.println(closed.error.message); }
}

def main() -> i32 {
    def mut owner: arena.GeneralArena = arena.GeneralArena.create();
    defer owner.free();

    def environment: [string; 1]     = {"GLOIN_GREETING=Hello from a child"};
    def mut options: process.Options = process.Options.defaults();
    options.cwd                 = "/";
    options.inherit_environment = false;
    options.environment         = environment[..];
    options.piped               = true;
    options.new_process_group   = true;
    options.stack_limit_bytes   = 2097152;

    // A shell runs only because we explicitly launch it. No implicit expansion.
    def arguments: [string; 2]         = {"-c", "printf '%s\n' \"$GLOIN_GREETING\"; pwd -P"};
    def started: result<process.Child> = process.start_with(&owner, "/bin/sh", arguments[..], options);

    if started.erroneous { std.println(started.error.message); return 1; }

    def mut child: process.Child = started.value;
    defer cleanup(&child);

    def input: [u8; 0]         = {};
    def mut output: [u8; 1024] = zeroed;
    def mut errors: [u8; 1024] = zeroed;
    def captured: result<process.Output> = child.communicate(input[..], output[..], errors[..],
        time.Duration { nanoseconds: 5000000000 });

    if captured.erroneous { std.println(captured.error.message); return 2; }

    def outcome: process.Output = captured.value;

    std.print(strings.view_bytes(outcome.stdout));

    if !outcome.status.success() { return 3; }

    return 0;
}

This prints the greeting and /. new_process_group = true gives the command its own cleanup group. terminate, kill and close target that group and the direct child, even after the leader exits. For grouped handles, poll/wait cache exit status but retain the native leader until close; close promptly to release that wait status. Retaining the leader prevents reuse of its ID before cleanup. Successful communication also performs group cleanup.

A nonzero stack limit uses a child-only fork/setup/exec path; zero keeps the default spawn path. On macOS it requires the host's original main thread: ordinary Gloin main works, but a worker-thread embedder receives an error. Linux supports either thread and requires descriptor range closure. Launch itself has no deadline. The soft stack limit does not cap heap usage or provide containment, and the program can raise it again up to its inherited hard ceiling. Read the platform rules, launch rationale and costs.

Group cleanup is not process-tree containment: descendants can leave the group, and host permissions apply. Only the direct child is reaped by this handle. Default start/start_piped still affect only the direct child. Resource limits other than stack, explicit search paths and individual stream redirection remain pending. See the complete API, ownership and limits and runnable options example.

Bounded JSON

import "@json"; adds a reader and writer implemented in Gloin. Both use built-in result<T> for errors, caller-owned byte storage, and an explicit nesting limit up to 64. The reader consumes a complete input string and produces structural, key, and scalar events. It checks UTF-8 and Unicode escapes while keeping number tokens exact until you request a native numeric conversion.

Read strings from a document

import "@json";
import "@std";

def main() -> i32 {
    def made: result<json.Reader> = json.Reader.create(
        "{\"message\":\"Hello, \\u4e16\\u754c!\"}", 256, 8
    );
    if made.erroneous { return 1; }
    def mut reader: json.Reader = made.value;
    def mut storage: [u8; 64] = zeroed;
    def mut complete: bool = false;
    while !complete {
        def next: result<json.Event> = reader.next();
        if next.erroneous {
            std.println(next.error.message);
            return 2;
        }
        def event: json.Event = next.value;
        if event.kind == json.DONE {
            complete = true;
        } else if event.kind == json.STRING {
            def decoded: result<string> = event.as_string(storage[..]);
            if decoded.erroneous { return 3; }
            std.println(decoded.value);
        }
    }
    return 0;
}

This prints Hello, 世界!. A KEY event precedes its value; decode keys before comparing them so escaped spellings are handled correctly. Decoded text borrows storage until its next modification. event.raw borrows the original token, and event.offset gives its byte position. Object and array begin/end events let you track a nested schema.

Consume DONE to validate the whole input. Earlier events can precede a later syntax error. Use json.validate(text, max_bytes, max_depth) first when application changes must wait for a valid document. Duplicate keys remain separate events in input order; enforce uniqueness in the application if required.

Build a request body

import "@json";
import "@std";

def main() -> i32 {
    def mut bytes: [u8; 128] = zeroed;
    def made: result<json.Writer> = json.Writer.create(bytes[..], 4);
    if made.erroneous { return 1; }
    def mut writer: json.Writer = made.value;
    def opened: result<void> = writer.begin_object();
    if opened.erroneous { return 2; }
    def key: result<void> = writer.key("message");
    if key.erroneous { return 3; }
    def value: result<void> = writer.string_value("Hello\nworld");
    if value.erroneous { return 4; }
    def closed: result<void> = writer.end_object();
    if closed.erroneous { return 5; }
    def finished: result<string> = writer.finish();
    if finished.erroneous { return 6; }
    std.println(finished.value);
    return 0;
}

The writer inserts commas, colons and escapes. It also provides arrays, number(text), boolean(value), and null_value(). Number text is validated without conversion through floating point. For a typed integer, use std.to_string_<width>, check its result, then pass the text to number.

Only publish a successful finish() value. A failed operation poisons the writer and may leave partial output; create a new writer to retry. Writer copies share bytes but copy counters, so pass one owner through &json.Writer. Reader copies advance independently over shared immutable input. No automatic object tree or struct serialization is provided.

A finished writer view can be an HTTP request body with Content-Type: application/json. Keep its storage live until upload finishes. JSON reading requires a complete buffered body even when HTTP transport is streaming. The full JSON guide specifies grammar, Unicode policy, limits, ownership, and exact numeric conversions. The packaged example builds and reads a nested payload, including the largest u64.

Nonblocking TCP, TLS, and HTTP

The 0.1.0 candidate adds @net for IPv4 TCP and verified client TLS, and @http for bounded HTTP/1.1 request and response heads. Socket operations return built-in result<T>; inspect .erroneous before reading a success value. Ordinary network states stay in the success payload: a pending connection is false, an unavailable accept has available == false, a read can report status.WOULD_BLOCK or status.END, and a timed readiness wait returns zero bits. Socket copies share ownership state, so close a socket before freeing its arena.

import "@arena";
import "@net";

def cleanup(socket: &net.Socket) -> void {
    if !socket.is_open() { return; }
    def closed: result<void> = socket.close();
    if closed.erroneous { return; }
}

def main() -> i32 {
    def mut owner: arena.GeneralArena = arena.GeneralArena.create();
    defer owner.free();
    def opened: result<net.Socket> = net.Socket.open(&owner);
    if opened.erroneous { return 1; }
    def mut socket: net.Socket = opened.value;
    defer cleanup(&socket);
    def started: result<bool> = socket.connect(net.Address.loopback(8080));
    if started.erroneous { return 2; }
    if !started.value {
        def ready: result<i32> = socket.wait(net.WRITABLE, 1000);
        if ready.erroneous { return 3; }
        if ready.value == 0 { return 4; }
        def finished: result<bool> = socket.finish_connect();
        if finished.erroneous { return 5; }
        if !finished.value { return 6; }
    }
    def closed: result<void> = socket.close();
    if closed.erroneous { return 7; }
    return 0;
}

This sketch expects a listener on localhost:8080; its deferred cleanup closes the socket before freeing its arena. The packaged network_http.gloin example creates its own listener, cleans up on every path, and completes a local HTTP exchange. It is runnable with gloinc --jit examples/network_http.gloin or as a native executable.

Socket.read([u8]) and write([const u8])/write_text(string) each make one nonblocking call. Check the returned byte count and retry after readiness; a successful write may be short. strings.view_bytes(buffer[0..count]) borrows received bytes as counted text. Pass that view to http.parse_request or http.parse_response, append more bytes while the successful payload has complete == false, then use header_bytes to locate the body. http.frame_request and http.frame_response report when a bounded fixed-length body is complete and return its borrowed view. http.format_get and http.format_response build heads in a caller-owned arena and return result<string>. The incremental http.ResponseReader also decodes chunked and clean-EOF response bodies and handles HEAD, bodyless statuses, and informational responses. Chunked requests, asynchronous DNS, IPv6, and UDP remain pending. The networking guide gives the exact ownership, framing, and error rules.

@http_client provides a streaming Exchange state machine and a synchronous request wrapper over it. Both accept an explicit address, verified TLS settings, validated headers, caller-owned buffers, and an overall deadline. HTTP 4xx/5xx statuses are response values; transport, framing, and limit failures return error. Each exchange closes on completion, failure, or explicit cancellation. URL parsing, redirects, decompression, connection pooling, and unknown-length uploads remain future work. The separate JSON module handles bounded request construction and complete buffered response bodies. See the complete client guide and JSON POST example.

Run gloinc --jit examples/http_echo_server.gloin in one terminal and gloinc --jit examples/http_client.gloin in another. The Gloin fixture server handles one loopback POST with bounded buffers and a 30-second deadline, then exits; restart it for another request. Repository HTTP/HTTPS acceptance also runs in Gloin, with independent wire expectations, delayed responses and 32 concurrent connections in JIT, -O0 and -O2. All repository-owned Python tooling has been migrated; see the validation record.

Streaming several HTTP exchanges

Create each Exchange with a StreamingRequest containing a known content_length, four disjoint Buffers (head, receive, send, body), and Limits for request head, total response metadata/body, and timeout. The total body limit is independent of the reusable body-buffer size. Keep all buffers and the arena live until cleanup; copies of an exchange share one state.

step(ready) stateWhat the program does next
PROGRESSGive other exchanges a turn, then call step(0) again.
WAITWatch the borrowed socket with net.wait_many, then pass returned readiness bits to step.
NEED_INPUTCall supply(bytes) and advance by its accepted byte count. If input is paused, keep watching for early responses and schedule the deadline.
HAVE_OUTPUTProcess the borrowed output() bytes and call consume(count). Unconsumed output pauses socket I/O for this exchange.
COMPLETEFraming succeeded and the connection closed; inspect head() for status and headers.

Use a zero-timeout poll while any exchange can run; otherwise wait until the nearest active deadline. Deadlines include pauses for input and output, but require the program to call step when they expire. A final response stops further upload bytes. cancel() closes resources and affects every alias; defer it before freeing the arena. Output can precede a later truncation or TLS error, so treat only COMPLETE as a successful response. The 32-connection example validates large binary bodies through 1 KiB output buffers while a stalled peer remains open, then cancels it. The streaming guide explains ownership, scheduling, and exact limits. For custom transports, http.ResponseDecoder exposes the same framing logic with consumed/produced byte counts and no I/O.

A listener can call set_reuse_address(true) before binding. To print an OS-assigned u16 port, use std.to_string_u16(&memory, address.port) and check the returned result<string>. The networking milestones cover concurrent servers, DNS, outbound HTTPS, and WebSocket support.

net.wait_many watches several sockets with caller-owned output and scratch arrays; Socket.shutdown_write() sends an orderly TCP FIN. net.resolve_ipv4 resolves hostnames synchronously and may block on DNS. On a connected socket, start_tls_client(&owner, hostname, trust_file) begins a verified TLS client session. Call handshake() until it returns zero, waiting for the returned readiness bit between attempts; use TlsClient.read and write for encrypted bytes. See the TLS client contract.

Server TLS and authenticated shutdown

Load one net.TlsServerConfig from a PEM certificate chain and unencrypted private key, then start a session on each accepted socket. Loading checks the key matches and reads files synchronously; it never prompts for a password. TLS 1.2 and 1.3 are supported. Sessions retain their own native configuration reference, so existing connections survive configuration closure. There is no client-certificate authentication, ALPN or automatic certificate reload.

// Inside a result-returning function; socket is an accepted TCP connection.
def loaded: result<net.TlsServerConfig> =
    net.TlsServerConfig.load(&owner, "chain.pem", "key.pem");
if loaded.erroneous { return loaded.error; }
def mut config: net.TlsServerConfig = loaded.value;

def started: result<net.TlsServer> = socket.start_tls_server(&owner, &config);
if started.erroneous { return started.error; }
def mut tls: net.TlsServer = started.value;
// Drive handshake, read/write and shutdown with readiness waits and a deadline.
// Close tls before socket; close config before freeing its arena.

TlsServer and TlsClient share the same handshake/read/write contract. For a blocked write, retry the same bytes and length; advance only by the returned count. Drain expected application data before calling shutdown(). It returns result<i32>: zero only after both authenticated close alerts have been exchanged, otherwise the readiness event to wait for. Starting shutdown prohibits further writes. A peer that closes TCP without its TLS alert produces an error, not status.END. Shutdown has no automatic deadline; the caller supplies one.

Successful shutdown still owns native resources. Call tls.close(), then socket.close(), before freeing the arena. Copies share ownership and closure affects all aliases. Close after fatal errors too; close provides cleanup and only a best-effort alert. A socket that has carried TLS cannot resume plaintext traffic or start another TLS session.

The runnable TLS server accepts one loopback connection, exchanges fixed PING/PONG bytes and closes gracefully under a 30-second deadline. The complete server guide includes OpenSSL client commands, ownership, native memory costs, platform behavior and limitations. A reusable HTTP server framework, IPv6, WebSockets and complete Slack integrations remain future work.

Support and limits

This development snapshot targets Apple Silicon macOS and Ubuntu 24.04 Linux on ARM64 and x86_64. Ubuntu ARM64 passed local core, complete-suite classification, and package acceptance; hosted macOS and x86_64 CI passed. Windows support is not planned; contributions are welcome. Cross compilation and Intel macOS are outside the validated target. Maps, enum payloads and pattern matching, packed bitfields, external packages, and concurrency remain future work. Results currently require direct checks on named bindings, and errors contain static messages only.

Native objects and executables target the current supported host. Executables do not need LLVM at runtime. The compiler and native linking step require the pinned toolchain. Objects require the static Gloin runtime at link time.
