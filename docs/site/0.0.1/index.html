Get started

Gloin 0.0.1 runs on Apple Silicon macOS. Install Xcode Command Line Tools, CMake 3.28+, Ninja, and LLVM/MLIR 21.1.6. From a source checkout:

bash scripts/install-llvm.sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DLLVM_DIR=/opt/homebrew/opt/llvm/lib/cmake/llvm \
  -DMLIR_DIR=/opt/homebrew/opt/llvm/lib/cmake/mlir
cmake --build build -j 2
./build/gloinc examples/hello_world.gloin

The last command prints Hello World!. Install with cmake --install build --prefix "$HOME/.local". The compiler needs the LLVM installation it was built against; generated executables link the Gloin runtime and do not need LLVM at runtime.

Save this as hello.gloin:

import "@std";

def main() -> i32 {
    std.println("Hello World!");
    return 0;
}
./build/gloinc hello.gloin
./build/gloinc --emit-exe -o hello hello.gloin
./hello

Compiler and native output

gloinc [--run | --check | --emit-ir | --emit-llvm | --emit-object | --emit-exe] \
       [-o PATH] [--stdlib-dir DIR] [--] FILE [-- ARG...]
gloinc --help
gloinc --version
ModeBehavior
default / --runJIT runs main() -> i32. Its low eight bits become the process exit status. Use FILE -- ARG... for program arguments.
--checkParse, type check, and verify without running. Main is optional.
--emit-ir, --emit-llvmPrint verified high level or LLVM dialect MLIR for inspection.
--emit-object -o PATHWrite a macOS arm64 object with a native entry point. Link it with libgloin_runtime.a using the pinned clang++.
--emit-exe -o PATHLink a macOS arm64 executable with the static Gloin runtime. Pass arguments directly to that executable.

Source, output, and link errors go to stderr and exit 1. Usage errors exit 2. Successful checks and emission exit 0. Runtime arithmetic traps terminate the program. Quote paths with spaces. --stdlib-dir DIR selects a directory of @ modules.

Syntax

Source is UTF-8. Comments start with //. Bindings, assignments, call statements, returns, imports, and defer statements end in ;. Function and control flow bodies use braces with no trailing semicolon. Declarations start with def; pub or priv follows def, with private as the default across modules.

def const LIMIT: i32 = 42;
def pub calculate(x: i32) -> i32 { return x + LIMIT; }
// Within a function:
def mut count: i32 = 0;

All bindings, parameters, fields, and return types need explicit types. A local may be declared without an initializer but must be assigned before use. Constants need compile time expressions. There are no implicit numeric conversions.

Types and expressions

booltrue or false; conditions require bool.

Integer literals accept decimal, 0x hexadecimal, and 0b binary spelling. Floating literals use decimal spelling and typed context. Operators include + - * / % (remainder for integers), comparisons, unary !, &&, and ||. Boolean operators short circuit. Integer overflow, division by zero, and non-finite floating results trap at runtime; invalid constants are compile errors.

Functions and control flow

def add(a: i32, b: i32) -> i32 { return a + b; }
def main() -> i32 {
    def mut total: i32 = 0;
    for def mut i: i32 = 0; i < 3; i = i + 1 {
        if i == 1 { total = add(total, 20); }
        else { total = add(total, 11); }
    }
    return total;
}

Use if/else, unless, while, and C style for with braced bodies. Functions can call forward declarations and recurse. Calls evaluate arguments left to right. defer call(...); captures arguments when reached and runs calls in reverse order on normal return. Traps do not unwind defers.

Structs and memory

def struct Counter {
    def pub mut value: i32,
    def pub static make(start: i32) -> Counter {
        return Counter { value: start };
    }
    def pub increment(self: *Counter) -> void {
        self.value = self.value + 1;
    }
}

Fields and methods use declared visibility. Instance methods declare typed self; static calls use Type.method(...). @arena supplies GeneralArena with initialized typed allocation, reset, and free. Reset invalidates values while retaining blocks; free releases storage. Pointer and arena lifetimes are manual. See the arena guide.

Modules

import "@std";
import "./utils";
def main() -> i32 {
    std.println("ready");
    return utils.calculate(40);
}

@name loads name.gloin from the standard library directory. Relative imports resolve from the importing source file. A module exposes its pub functions, constants, and structs through its namespace. Only the root file supplies main; imports have no runtime initialization. Import cycles, missing files, and private access produce diagnostics.

Modules live in stdlib/ in a build and share/gloinc/stdlib/ after installation. Arena backed strings borrow caller owned storage. The linked guides give signatures, ownership, errors, and costs.

Support and limits

Version 0.0.1 supports Apple Silicon macOS only. Linux is planned for 0.1.0. Windows support is not planned; contributions are welcome. Cross compilation and Intel macOS are outside 0.0.1. Arrays, generics, enums, packed bitfields, external packages, and concurrency remain future work.

Native objects and executables target the current Apple Silicon host. Executables do not need LLVM at runtime. The compiler and native linking step require the pinned toolchain. Objects require the static Gloin runtime at link time.
